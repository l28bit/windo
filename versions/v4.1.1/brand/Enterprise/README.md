# WINDO Enterprise Polish Final Asset Pack

This pack is the contained WINDO brand system.

## Final mark decision

- No overlap.
- All elements are contained inside the shield.
- Internal split separates command intent from Windows execution space.
- Large assets use the full `>_` prompt.
- 16px and 24px tray contexts simplify the prompt for readability.

## Included

- Full logos: dark and light SVG/PNG
- Contained brand mark variants: blue, dark, light, cyan, silver, mono white, mono black
- Tray state PNGs and real multi-size Windows ICO files
- Status icons
- UI icon family
- Badge assets
- Manifest
- Export scripts
- Contact sheet preview

## Color system

- Dark navy: #07111F
- Deep navy: #0B1220
- Windows blue: #0078D4
- Electric blue: #00A8FF
- Cyan/elevated: #00C2D6
- Green/allowed: #22C55E
- Yellow/warning: #FFC400
- Red/denied: #E53935
- Silver/neutral: #A7B0BC
- White: #FFFFFF

## Windows ICO sizes

Each tray ICO includes:

- 16x16
- 24x24
- 32x32
- 48x48
- 64x64
- 128x128
- 256x256

## Usage

Use SVG files as source assets for design and docs. Use PNG files for application UI, web, README content, GitHub avatars, and documentation. Use ICO files for Windows tray/app integration.

## Regeneration

Install Inkscape and ImageMagick, then run:

PowerShell:
`./export-assets.ps1`

Bash:
`./export-assets.sh`
