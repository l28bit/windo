# Release notes - WINDO v5.1.1

![WINDO banner](../../brand/assets/banners/banner-blue-left.png)

v5.1.1 is a surface-polish release for the Exodus Limited Edition.

## Designed operator surfaces

- `windo dashboard --html` now renders with the branded dark operator visual system, stronger health cards, clearer issue treatment, better audit tables, and final WINDO banner assets.
- `windo launchpad --html` now carries the Exodus Limited Edition identity with a more polished command-center layout and responsive action sections.
- `windo launchpad --tray` now opens a redesigned Windows Forms Command Center window instead of a plain button list.

## Tray and toast polish

- The tray popup uses a scrollable action layout with command text kept visible beside each action.
- A local status toast window gives quick next commands without requiring a browser.
- Tray balloon copy now matches the Exodus Limited Edition release language.

No trust boundary changes: actions still open visible PowerShell windows, curated control-plane actions remain explicit, and dashboard/launchpad HTML artifacts are local-only.
